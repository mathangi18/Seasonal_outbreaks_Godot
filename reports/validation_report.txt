## Changes & Fixes
The following files were modified to ensure Godot 4.x compatibility and adherence to specs:

### 1. Signals & Callables
- **File**: `scripts/SimulationEngine.gd`, `scripts/Facility.gd`
- **Change**: Replaced `emit_signal("name")` with `name.emit()`.
- **Rationale**: Godot 4.x signal syntax.
- **Docs**: [Using Signals](https://docs.godotengine.org/en/stable/getting_started/step_by_step/signals.html)

### 2. JSON Parsing
- **File**: `scripts/HUD.gd`
- **Change**: Replaced `JSON.parse(text)` with `JSON.parse_string(text)` and `JSON.new().parse(text)`.
- **Rationale**: `JSON.parse` is static and returns Error in Godot 4. Instance method required for data.
- **Docs**: [JSON Class](https://docs.godotengine.org/en/stable/classes/class_json.html)

### 3. Instantiation
- **File**: `scripts/SimulationEngine.gd`
- **Change**: Fixed `scale_utils` instantiation fallback to properly set name and add as child.
- **Rationale**: Ensure consistent node tree structure.
- **Docs**: [Node Class](https://docs.godotengine.org/en/stable/classes/class_node.html)

### 4. UI Signals
- **File**: `scripts/HUD.gd`
- **Change**: Updated `OptionButton` signal connection to `item_selected.connect`.
- **Rationale**: Type-safe signal connection.
