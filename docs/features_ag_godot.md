# Features: Seasonal Outbreaks (Godot)

## 1. Simulation
- **Infection**: Proximity-based spread.
- **States**: Susceptible, Exposed, Infectious, Symptomatic, Recovered, Hospitalized.
- **Service**: Facilities process patients.

## 2. Entities
- **Patient**: Wandering agents.
- **Facility**: Static service points.
- **Ambulance**: Dispatched vehicles.

## 3. Technical
- **Headless**: Validation scripts.
- **CI**: GitHub Actions.
- **Logs**: CSV logging (planned).
