# Repo structure

assets/  
  originals/        → source PNG art used by the scenes  
scenes/             → .tscn scene files (Main, Patient, Facility, Ambulance, HUD, World)  
scripts/            → GDScript source logic  
res/                → helper or debug scripts/resources  
docs/               → onboarding, guides, features  
README.md           → project overview  
.gitignore          → ignores editor caches and imports  

Notes:
- Do not commit .import files or .godot editor cache  
- Always keep PNG artwork in assets/originals
