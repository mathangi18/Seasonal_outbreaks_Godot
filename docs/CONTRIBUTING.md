# Contributing Guide

Branching:
  git checkout -b feat/<name>/<topic>

Pull Requests:
- Target main
- Keep changes focused and small
- Add a reviewer before merging

Tools policy:
- Automated tools may be used for drafts
- All code must be reviewed and adjusted to project style
- Remove bulky generated comments before merging

Testing:
- Run scenes/Main.tscn
- Provide logs when reporting errors
